📚 Regex Cheat Sheet

\d
Any digit (0-9)
\w
Word character (a-z, A-Z, 0-9, _)
\s
Whitespace character
.
Any character except newline
^
Start of string
$
End of string
[abc]
Any of a, b, or c
[^abc]
Not a, b, or c
a|b
a or b
\b
Word boundary
