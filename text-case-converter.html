📚 Case Format Examples

🔠 UPPERCASE
All letters are capitalized. Commonly used for titles, headers, or to indicate shouting in digital communication.
🔡 lowercase
All letters are in lower case. Often used for programming variables, casual writing, or to convey quiet tone.
📝 Sentence Case
First letter of the first word in each sentence is capitalized. Standard for most formal writing.
🏷️ Title Case
First letter of each major word is capitalized. Used for book titles, headings, and formal titles.
🐫 camelCase
First word lowercase, subsequent words capitalized with no spaces. Common in programming for variables.
📦 PascalCase
First letter of every word capitalized with no spaces. Used for class names in programming.
🐍 snake_case
All lowercase with underscores between words. Common in programming for file names and variables.
🚂 kebab-case
All lowercase with hyphens between words. Used in URLs, CSS classes, and file naming conventions.
