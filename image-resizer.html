Image Resizing API

Integrate our powerful image resizing functionality into your applications with our REST API. Perfect for developers building CMS platforms, e-commerce systems, or digital asset management solutions.

POST https://api.imageresizer.com/v1/resize
Content-Type: multipart/form-data
Body: {
  image: [file],
  width: [integer],
  height: [integer],
  maintain_aspect_ratio: [boolean],
  quality: [10-100],
  format: [jpeg|png|webp|gif],
  batch: [boolean]
}

Response: {
  success: true,
  resized_url: "https://cdn.imageresizer.com/resized/xyz.jpg",
  original_dimensions: {width: 1920, height: 1080},
  resized_dimensions: {width: 800, height: 600},
  original_size: "2.1MB",
  resized_size: "245KB",
  reduction: "88%"
}
