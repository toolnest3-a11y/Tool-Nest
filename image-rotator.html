Image Transformation API for Developers

Integrate our powerful image rotation and flipping functionality into your applications with our REST API. Perfect for developers building photo editing apps, CMS platforms, or digital asset management solutions.

POST https://api.imagetransformer.com/v1/transform
Content-Type: multipart/form-data
Body: {
  image: [file],
  rotation: [0-360],
  flip_horizontal: [boolean],
  flip_vertical: [boolean],
  quality: [10-100],
  format: [jpeg|png|webp|gif],
  batch: [boolean]
}

Response: {
  success: true,
  transformed_url: "https://cdn.imagetransformer.com/processed/xyz.jpg",
  original_orientation: "landscape",
  transformed_orientation: "portrait",
  rotation_applied: "90",
  flip_applied: {horizontal: true, vertical: false}
}
